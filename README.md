# Retirement Decoded — IRMAA Appeal Kit waitlist page

Одностраничный лендинг для измерения спроса на продукт **The IRMAA Appeal Kit** до подключения приёма платежей.

Задача страницы — не продать, а **замерить спрос**: сколько людей из аудитории YouTube готовы оставить email за продукт по $19. Ни платёжной платформы, ни KYC, ни банковских реквизитов для этого не нужно.

## Что внутри

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся страница: один файл, без сборки, без зависимостей, без JavaScript |

Особенности вёрстки — под аудиторию 60+:

- базовый кегль 20px (19px на телефоне), межстрочный 1.65;
- serif-шрифт и высокий контраст текста;
- кнопки на всю ширину, высота нажатия ~64px;
- одна колонка, никаких popup, никаких анимаций;
- семантическая разметка, видимый focus-ring, `skip to content` для скрин-ридеров.

## Настройка перед публикацией

В `index.html` два плейсхолдера. Замени их на ссылки своих Google Форм:

| Плейсхолдер | Куда ведёт |
| --- | --- |
| `PASTE_WAITLIST_FORM_URL_HERE` | форма листа ожидания (главная кнопка) |
| `PASTE_CHECKLIST_FORM_URL_HERE` | форма выдачи бесплатного Age-65 Checklist |

## Как сделать формы (бесплатно, без платёжных данных)

Google Формы + Google Диск закрывают и сбор email, и автоматическую выдачу бесплатного PDF.

**Форма листа ожидания**

1. forms.google.com → новая форма → название `The IRMAA Appeal Kit — Waitlist`.
2. Одно обязательное поле: `Email` с типом ответа «Email» и включённой проверкой.
3. Настройки → «Ответы» → включить «Собирать адреса электронной почты», если хочешь дублирующую проверку.
4. Настройки → «Презентация» → «Сообщение для респондентов»: `You're on the list. You'll hear from me the day the kit opens — nothing else.`
5. «Отправить» → значок ссылки → «Сократить URL» → вставить в `PASTE_WAITLIST_FORM_URL_HERE`.

**Форма бесплатного чек-листа (с автовыдачей файла)**

1. Загрузить `Age-65_Medicare_Checklist_FREE.pdf` на Google Диск.
2. Открыть доступ по ссылке: «Все, у кого есть ссылка» → «Читатель». Скопировать ссылку.
3. Создать форму с одним полем `Email`.
4. Настройки → «Презентация» → «Сообщение для респондентов»: `Thank you — here is your checklist:` и вставить ссылку на файл.
5. Вставить ссылку формы в `PASTE_CHECKLIST_FORM_URL_HERE`.

Так покупатель получает файл сразу после отправки формы, без ручной работы и без сервиса рассылок.

## Публикация на GitHub Pages

1. Закоммитить `index.html` в ветку `main`.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main`, папка `/ (root)` → Save.
3. Через 1–2 минуты страница доступна по адресу `https://olyaolya89.github.io/Devin/`.

Хостинг бесплатный, платёжные данные не требуются.

## Как читать результат

Ссылку на страницу ставим в описание видео про IRMAA и в закреплённый комментарий. Замеряем за 3–4 недели:

| Метрика | Где смотреть | Порог «спрос есть» |
| --- | --- | --- |
| Переходы на страницу | YouTube Studio → Аналитика → Внешние ссылки | больше 1% от просмотров видео |
| Заявки в лист ожидания | Google Форма → «Ответы» | 200+ за первый месяц |
| Заявки на чек-лист | вторая форма → «Ответы» | 5–10% от переходов |

Если пороги пройдены — спрос подтверждён, можно подключать приём платежей и рассылку. Если сильно ниже — переделываем оффер и заголовок видео до того, как вложены деньги.

## Юридическое

В футере страницы обязательны и не удаляются:

- дисклеймер «educational information only»;
- прямое указание, что Retirement Decoded не аффилирован с SSA, CMS и Medicare;
- указание, что цифры относятся к 2026 году и могут меняться;
- отсутствие любых обещаний одобрения заявления или конкретной экономии.

Цифры на странице (Part B $202.90, пороги $109,000 / $218,000, брекеты до $689.90) сверены с фактшитом CMS «2026 Medicare Parts A & B Premiums and Deductibles».
