# Шаблоны сценария (английский, под ElevenLabs)

Подставлять реальные проверенные факты. Длина в скобках дана при темпе ~160 слов в минуту.

## A. Ranking: «Every Position Inside a [N]-Man [MACHINE] Ranked From Safest to Deadliest» (20–24 мин, 3 300–3 900 слов)
```
[HOOK ~120 words]
In [year], the [machine] was [reputation in one fact + everyday comparison].
To [observer: a ground crewman on X / a factory worker in Y], it looked like [the safe assumption].
The [N] men inside knew better. Every seat in that [hull/fuselage] had its own way of killing you,
and some killed much faster than others.
This is every position inside the [machine], ranked from the safest to the deadliest,
and the reason each one sits exactly where it does.

[TOUR ~300 words]  nose → tail, who sits where, which way he faces, how many compartments.
"[N] men, [K] compartments, and one of these seats was far deadlier than the rest."

[SHARED LIFE ~300 words]  noise / air / cold / body / sleep — what every man had in common.

[METHOD ~200 words]  "We could not find…" → three tests you can check → "Where the records confirm…"

[COUNTDOWN #N … #3, each 250–400 words]
Number [k], [position]. Fact → "Why number [k]?" → named case (rank, name, date, unit, aircraft name)
→ sting line → bridge line teasing the next man.
(At ~50%: mid-roll subscribe with "because…" open loop.)

[#2 and #1, 400–600 words each]  the strongest cases; #1 carries the paradox.

[EVACUATION PICTURE ~200 words]  "So, picture the moment…" — who goes out where, who stays.

[QUESTION]  "Which seat would you have taken? … It is harder than it sounds. Tell us in the comments."
[RING ENDING]  callback to the hook observer → one line per seat → aphorism.
[END SCREEN]  "If you want to see how the [other machine] compares, that ranking is on screen now…"
```

## B. «What It Was Like to Fight Inside a [MACHINE] [POSITION] at [N] Feet» (16–19 мин, 2 600–3 000 слов)
```
[HOOK]  reputation/paradox → man #1 + date + catastrophe → man #2 + date + catastrophe teased (open loop)
→ "These are 12 things the [position] did to the man inside it, in the order a mission brought them."
[TOUR]  where the seat is, armor, guns, crew list, "He saw only where it had been."
[PLANT]  "Remember how [narrow/cold/alone] that [seat] is, because it decides almost everything that follows."
[COUNTDOWN #12 → #1]  in mission order: rank → takeoff → equipment changes → ammo/oxygen → controls →
sight → the main threat (case of man #1) → mid-roll subscribe → new threat → D-Day/major date →
cold/hours → "the long way out" (case of man #2, closes the open loop) → "a name that did not fit" (myth vs fact)
[QUESTION]  "would you rather have [option of man #1] or [option of man #2]? Tell us in the comments."
[RING ENDING + END SCREEN]
```

## C. «What Happened to [N] [Crewmen] When [EVENT]» (18–21 мин, 2 900–3 300 слов)
```
[HOOK]  date + place + machine + crew size + the moment it went wrong (stop before the outcome)
→ "This is what the records say happened to each of the [N] men — and what they do not say."
[CREW & SEATS]  each man by name on the cutaway, which way he faced, how he would get out.
[THE MISSION]  takeoff, formation, target, timeline with exact times.
[THE MOMENT]  second by second, cutaway with highlight on each man as the story reaches him.
[MAN BY MAN]  what happened to each (survived / POW / killed / missing), "accounts differ" where needed.
[AFTER]  rescue, POW camp, medals, memorial, what changed in tactics because of it.
[QUESTION]  "Your seat: [position A], [position B] or [position C]? Tell us in the comments."
[RING ENDING + END SCREEN]
```

## Подготовка для ElevenLabs
- Числа писать так, как их надо прочитать: «12,000 feet», «the 17th of May, 1943», «B-twenty-six» (если голос путает).
- Паузы ставить тегами Ольги `[PAUSE]` после sting-фраз и перед «Number …».
- Делать сразу второй файл: дословный перевод на русский теми же блоками.
