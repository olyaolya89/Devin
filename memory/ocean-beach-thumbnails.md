# 5 вариантов превью — Ocean Beach's $3M Homes Are Losing the Great Highway

## Формула референсов (по трём скриншотам конкурентов)
- Фотореалистичный кадр 16:9, чаще с дрона или с низкого ракурса; один главный объект (дом/башня) + одна видимая угроза (обрыв, вода, трещина).
- Пасмурное штормовое небо, холодная серо-синяя палитра, мокрые поверхности; дом — светлый/стеклянный, чтобы контрастировать с тёмным фоном.
- Обязательная трещина/разрушение крупным планом на переднем плане (асфальт, фундамент, край обрыва).
- Текст в левом нижнем углу, две строки: красный блок «BREAKING» + белый блок с местом; ниже большой белый блок с 2–3 словами капсом (NO POWER / CAN'T SELL / ALERT / TRAP?).
- Правый нижний угол свободен под длительность ролика. Никаких лиц, никаких логотипов.

Общие технические параметры для всех промтов (добавлять в конец): `--ar 16:9`, 1920x1080, photorealistic, editorial drone photography, overcast stormy sky, high dynamic range, sharp focus, no text, no people, no watermark.

## Оформление текста (для всех, как в референсах)
- Шрифт: жирный гротеск, капс (Bebas Neue / Anton / Impact-подобный).
- Строка 1: красный блок #E5141C с белым «BREAKING» + белый блок с чёрным названием места.
- Строка 2: белый блок, чёрный текст, 2–4 слова, высота ~20% кадра.
- Лёгкое затемнение (виньетка) нижней трети, чтобы текст читался на мобильном.
- Один акцент на кадре (трещина, волна, знак) — не перегружать.

## Рекомендация
Начать с #1 (HIGHWAY GONE) — прямая визуализация названия, узнаваемый кадр с дрона, сразу читается «дорога исчезает». Запасной A/B: #5 ($3M FOR THIS?) — вопрос + цифра, как у референса с лучшим CTR-паттерном «TRAP?».
