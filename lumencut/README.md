# LumenCut v1

Локальный генератор видео из дословного сценария: озвучка Edge TTS (бесплатно), подбор картинок и видео из открытых источников (Wikimedia Commons, Openverse, Pixabay, Pexels), нарезка видео не длиннее 5 секунд, субтитры, рендер MP4 1080p через ffmpeg и студия для правок. Никаких кредитов и тарифов — всё работает на вашем компьютере.

## Установка на Windows (один раз, ~10 минут)

1. **Node.js** — скачайте установщик LTS с https://nodejs.org/ и установите, ничего не меняя в настройках.
2. **ffmpeg** — откройте PowerShell (Пуск → «PowerShell») и выполните:
   ```powershell
   winget install --id Gyan.FFmpeg -e
   ```
   Закройте и снова откройте PowerShell, проверьте: `ffmpeg -version`.
3. **Скачайте проект** — на GitHub нажмите зелёную кнопку **Code → Download ZIP**, распакуйте, например, в `C:\LumenCut`.
4. В PowerShell перейдите в папку и установите зависимости:
   ```powershell
   cd C:\LumenCut\lumencut
   npm install
   ```

## Установка на macOS

```bash
brew install node ffmpeg
cd lumencut
npm install
```

## Запуск (каждый раз)

```bash
cd lumencut
npm run dev
```

Откройте в браузере http://localhost:5173. Остановить — `Ctrl+C` в окне терминала.

## Первая настройка

Страница **Настройки** в шапке сайта: вставьте ключи (все бесплатные) и нажмите «Проверить ключи».

| Источник | Где взять ключ | Зачем |
| --- | --- | --- |
| Pixabay | https://pixabay.com/api/docs/ (ключ показан на странице после входа) | много видео и фото в 1080p |
| Pexels | https://www.pexels.com/api/ → Get Started → Your API Key | качественные стоковые видео |
| Gemini | https://aistudio.google.com/apikey | умные поисковые запросы по смыслу сцены (без ключа работает простая эвристика) |

Wikimedia Commons и Openverse работают без ключей. Ключи хранятся только в `data/settings.json` на вашем компьютере.

## Как пользоваться

1. **Стол** — вставьте сценарий, выберите голос, нажмите «Собрать видео».
2. **Очередь** — видно шаги (озвучка → поиск → нарезка → рендер) и журнал сборки; по готовности — плеер и «Скачать MP4».
3. **Студия** — по сценам: замена кадра кликом на любого из 12 кандидатов, правка текста субтитра, «Рендер видео» и «Скачать MP4».

Сценарий используется дословно: ничего не переводится и не переписывается. Язык озвучки определяется по тексту.

## Переменные окружения (необязательно)

Всё то же самое можно задать в `.env` (см. `.env.example`): `PIXABAY_API_KEY`, `PEXELS_API_KEY`, `LLM_PROVIDER=none|gemini|ollama`, `GEMINI_API_KEY`, `MAX_CLIP_SECONDS`, `FFMPEG_PATH`. Значения со страницы «Настройки» имеют приоритет.
