Сценарий и озвучка

Для черновика можно начать с текста. Для финального фильма нужна озвучка.

Научно-популярный режим проверяет покрытие сцен и источники перед экспортом. Монтажный план из Codex можно открыть вместе с подобранными файлами.

Стиль фильма

    Загрузите ролик, на который хотите быть похожи. Программа сама его посмотрит (2–4 минуты, вкладку не сворачивать): как долго держится кадр, сколько плавных переходов, какой цвет, насколько тихо играет музыка. Темп, цвет и звук анализируются в браузере. Отправка кадров для оценки графики включается отдельно.
