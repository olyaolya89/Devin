# Научно-популярный монтаж в LumenCut

## Работа с фильмом

1. Уточните тему, аудиторию, язык, длительность и референсы из задания. Если уже есть сценарий и голос, используйте их и сверяйте произнесённый текст. Для коротких тестов допустим локальный синтез речи. Для фильма без исходного текста сначала подготовьте сценарий с проверяемыми источниками.
2. Разбейте озвучку на смысловые отрезки по таймингу слов. Найдите для каждого отрезка конкретный объект или действие. Чередуйте масштаб кадров и планируйте вступление, развитие и развязку. Для тезисов о конкретном человеке, месте, виде, предмете или событии ищите именно их. Иллюстрации и реконструкции обозначайте в кадре, если зритель может принять их за документальную съёмку.
3. Сначала используйте свои материалы, открытые архивы с правами на конкретный файл и подходящий лицензированный сток. Откройте страницу исходника, проверьте автора, разрешение на использование, разрешение изображения и выбранный фрагмент. Размер канала и длина отрывка не предоставляют права на монтаж. Сравните начало, середину и конец каждого фрагмента, чтобы исключить внутреннюю склейку, обрезанный объект, чужую подпись и другие дефекты.
4. Соберите план по формату ниже. Стремитесь к тому, чтобы не менее половины таймлайна занимала реальная съёмка. Используйте графику для важных фактов. Избегайте повторов, декоративных эффектов поверх ключевых кадров и частой смены музыки. Если найден более точный факт, отразите расхождение при редакторской проверке.
5. Откройте план в LumenCut, выберите озвучку и прикрепите исходники. Проверьте первые 20 секунд и экспортируйте MP4. Проверьте файл со звуком, таймингом и склейками, особенно на границах глав. Сохраните рядом SRT и список авторов. Для своих загруженных музыкальных треков отдельно сохраните нужную атрибуцию.

По умолчанию LumenCut использует локальный подбор. Сохранённый ключ Gemini сам по себе не включает запросы. Gemini выбирают в текущем сеансе, он выполняет до одного запроса на 25 сцен. CLIP и Whisper выполняются в браузере. Первый запуск моделей скачивает их из сети.

Выберите «Тайминг для Codex · без поиска», чтобы получить монтажные точки из сценария и озвучки, минуя поиск и Gemini. Затем в раскадровке скачайте `lumencut-review.json`. В задании есть таймкоды, отметки слов, визуальные задачи, выбранные фрагменты и причины, по которым сцены ещё требуют проверки. Для готового проекта эту же выгрузку можно использовать для точечного исправления сцен. Импорт проверенного плана сохраняет монтажные точки и выбранные исходники.

Для точного объекта LumenCut предлагает кандидатов из архивов и оставляет выбор редактору. Подтверждайте кадр после сверки действия, места, эпохи и прав. Для каждой готовой сцены отметьте проверку и укажите тип каждого кадра. Монтаж показывает подписи к архиву, иллюстрациям и реконструкциям. Доля реальной съёмки включает документальные и лицензированные иллюстративные видео. Ориентир для фильма 55–65%.

## Подбор отдельных сцен в Codex

На вкладке «Сценарий и голос» откройте «Подбор ключевых кадров с Codex». По тексту сайт предлагает эпизоды с именами, датами и архивными признаками. Можно изменить список вручную и скачать `lumencut-codex-research.json` ещё до запуска Gemini. Прикрепите его в чат с коротким поручением подобрать кадры. Проверьте исходники и добавьте отобранные файлы в соответствующие сцены через «Выбрать файл». Дата и имя из автоматической разметки служат подсказками для проверки.

## Формат плана

Откройте JSON кнопкой «Открыть проект или монтажный план». Привяжите голос во вкладке «Сценарий и голос». Для материалов с полем `file` добавьте одноимённые файлы через «Раскадровка → Прикрепить файлы из монтажного плана». Альтернатива `file` — поле `url` с прямой HTTPS-ссылкой на медиа, доступное браузеру с CORS. Поле `page` ведёт на карточку источника. Исходники и голос прикрепляются заново после перезагрузки. JSON сохраняет монтаж, имена файлов и атрибуцию.

```json
{
  "format": "lumencut.production",
  "version": 1,
  "topic": "How auroras form",
  "voiceFile": "voice.wav",
  "shots": [
    {
      "text": "Green curtains ripple across the night sky.",
      "start": 0,
      "end": 3.6,
      "visual": "Wide shot of green aurora over a dark landscape",
      "subject": "Aurora borealis",
      "reviewed": false,
      "queries": ["aurora borealis night timelapse"],
      "mood": "wonder",
      "overlay": { "type": "title", "text": "AURORA", "word": "Green" },
      "cuts": [
        {
          "t0": 0,
          "t1": 3.6,
          "from": 1.4,
          "media": {
            "kind": "video",
            "file": "aurora.mp4",
            "source": "NASA",
            "author": "NASA / Mike Toillion",
            "license": "Public domain (NASA, US)",
            "licenseUrl": "https://www.nasa.gov/nasa-brand-center/images-and-media/",
            "page": "https://svs.gsfc.nasa.gov/15077/",
            "context": "exact"
          }
        }
      ]
    }
  ]
}
```

- Сцены и кадры идут подряд без пропусков и наложений. Время в секундах. `start` и `end` описывают сцену, `t0` и `t1` — кадр внутри сцены, `from` — точку входа в исходном видео. В научно-популярном стиле кадр длится до пяти секунд.
- `text` содержит слова диктора. Можно добавить `wt` с отметками начала каждого слова и `wordEnd` с концом реплики.
- Добавьте `subject` там, где важна точность объекта. Ставьте `reviewed: true` после проверки фрагментов, графики, контекста и прав. При изменении фрагмента или графики LumenCut попросит подтвердить соответствие заново.
- Для `context` используйте `exact` (точный кадр), `archive` (архив), `stock` (иллюстрация), `reconstruction` (реконструкция) или `graphic` (схема и анимация). Для старых планов поле `footage: "illustration"` отображается как реконструкция, контекст остальных архивных файлов можно указать в раскадровке. Фото передавайте с `kind: "image"`. Атрибуция по каждому кадру попадает в `credits.txt`.
- Поле `caption` добавляет на экран короткое уточнение к кадру, например «K Street, Sacramento · 1862». Для архивного портрета указывайте дату съёмки, если она отличается от даты события в озвучке.
- Поддерживаются документальные графические элементы `title`, `lowerthird`, `counter`, `stat`, `year`, `infocard`, `panel`, `checklist`, `chart`, `map`, `name`, `statement`. Указывайте факты из сцены. Поддерживаемые поля отображаются в редакторе раскадровки.
