# LumenCut Studio — сценарий → готовое видео (в браузере, бесплатно)

Сайт в стиле Kutly для faceless-роликов: вставляете сценарий и озвучку → сайт сам режет текст на сцены 2–5 сек,
понимает **смысл** каждой фразы, подбирает **неповторяющиеся** стоковые видео/фото, добавляет анимированный текст,
субтитры, музыку и звуковые эффекты (из плагина Razgon Animation Studio) и собирает MP4 **прямо в браузере**.
Ни сервера, ни ffmpeg, ни платных кредитов.

## Что нужно
- Google Chrome или Microsoft Edge (Windows 10/11), последняя версия.
- Бесплатные ключи (вводятся один раз во вкладке «Настройки», хранятся только в вашем браузере):
  - **Pexels** — https://www.pexels.com/api/ → «Get started» → после входа скопируйте ключ;
  - **Pixabay** — https://pixabay.com/api/docs/ → войдите → ключ показан в разделе «Parameters» (поле `key`);
  - **Gemini** — https://aistudio.google.com/apikey → «Create API key». Нужен для подбора кадров по смыслу.
  Без ключей сайт работает, но ищет только в Wikimedia (исторические фото) — качество хуже.

## Как пользоваться (по шагам)
1. Откройте сайт: `https://olyaolya89.github.io/Devin/lumencut-web/` (после слияния PR).
2. Вкладка **Настройки** → вставьте ключи → **Сохранить**. Галочки «Смысловой подбор CLIP» и «Предпочитать видео» оставьте включёнными.
3. Вкладка **1. Сценарий и голос** → вставьте английский сценарий → нажмите «Озвучка» и выберите MP3/WAV.
4. Нажмите **Сделать раскадровку**. Первый раз браузер скачает две нейросети (Whisper ~140 МБ и CLIP ~150 МБ) — 1–3 минуты, потом они берутся из кэша.
   - Whisper слушает озвучку и точно привязывает каждую фразу ко времени.
   - Gemini читает весь сценарий и для каждой фразы пишет «смысл» и «что показать» (например «долг рос» → «стопка неоплаченных счетов»), графику, звук и настроение музыки.
   - CLIP (нейросеть в браузере) сравнивает каждую найденную картинку со смыслом сцены и берёт самую подходящую.
   - Повторов нет: один и тот же файл не используется дважды, а визуально почти одинаковые кадры (даже с разных сайтов) отбрасываются.
   - Сцены длиннее 5 секунд автоматически получают несколько разных кадров — ни один кусок не длиннее 5 секунд.
5. Вкладка **2. Раскадровка**: проверьте сцены. Можно:
   - кликнуть по миниатюре внизу карточки — заменить кадр (занятые кадры бледные, их выбрать нельзя);
   - поправить «Смысл / что показать» или запросы и нажать **Найти заново**;
   - выбрать графику (keyword — жёлтая плашка, number — счётчик, date/place — плашка внизу слева, quote — цитата, chapter — заголовок главы), звук (▶ — прослушать) и музыку.
6. Вкладка **3. Рендер** → **Тест: первые 20 секунд** (проверить стиль) → **Рендер всего видео** → выберите, куда сохранить MP4.
   Не сворачивайте вкладку во время рендера. Скорость ≈ реальное время (8-минутный ролик ≈ 8–10 минут).
   Также скачайте `subtitles.srt` и `credits.txt` (авторы кадров — для описания видео).
7. **Сохранить проект** — сохраняет раскадровку в файл, чтобы вернуться к ней позже (озвучку потом выбрать снова).

## Звук
Все эффекты и музыка — процедурные, сгенерированы плагином Razgon Animation Studio (`audio/sfx.py`, `audio/music.py`), без лицензий и API:
- `sfx/` — 35 эффектов (whoosh, pop, blip, counter, riser, impact, stinger, ding, glitch…);
- `music/` — 11 настроений (mystery, tension, action, wonder, hopeful, sad, triumph, playful, calm, dark, epic).
Музыка автоматически приглушается под голосом (≈ −9 dB), итог нормализуется под YouTube (≈ −14 LUFS).

## Для разработчика
Чистый статический сайт (ES-модули, без сборки). Локально: `python -m http.server` в этой папке и открыть `http://localhost:8000`.
`js/plan.js` — сцены, тайминг, план Gemini · `js/sources.js` — Pexels/Pixabay/Wikimedia · `js/ai.js` — Whisper + CLIP (transformers.js) ·
`js/match.js` — смысловой подбор без повторов · `js/audio.js` — микс · `js/render.js` — графика и кодирование MP4 (WebCodecs + mp4-muxer, MIT).
